# Lowbit Planner

## About

A *life planner* tool to use without leaving the terminal.

## Install

```bash
# Clone this repo in a place of your choice:
git clone git@github.com:lowbit-inc/lowbit-planner.git

# Install the CLI to your path
cd lowbit-planner
./plan.sh install

# Try to use it
plan version
```
